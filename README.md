# Matthew Evans's Homebrew Tap

This tap contains Homebrew formulae maintained by [@matthewevans](https://github.com/matthewevans).

`Formula/git-reconcile.rb` will be published from the [git-reconcile](https://github.com/matthewevans/git-reconcile) release workflow. Install it with:

```sh
brew install matthewevans/tap/git-reconcile
```
